# Personal portfolio website

This is a static personal portfolio designed to be hosted free on GitHub Pages.

## Files
- `index.html` — page content
- `style.css` — layout and styling

## Publish free with GitHub Pages
1. Sign in or create a free account at https://github.com/
2. Create a **public** repository named exactly `YOUR-USERNAME.github.io` (replace YOUR-USERNAME with your GitHub username).
3. Upload `index.html` and `style.css` to the repository's root.
4. Open the repository's **Settings → Pages**.
5. Under build/deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
6. Wait a few minutes and open `https://YOUR-USERNAME.github.io`.

## Before publishing
- Review the profile name and LinkedIn link in `index.html`.
- Replace `hello@example.com` if you want an email contact (or remove the suggestion link).
- Check dates, job titles, and descriptions against your CV.
- The project cards are draft concepts based on themes discussed; replace with only accurate, non-confidential details.
- The page imports Google Fonts from the internet. If you prefer no third-party font request, remove the `@import` line at the top of `style.css`; the site will use fallback fonts.
- GitHub Pages is for static files. This site does not use a database or collect visitor information.
